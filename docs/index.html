MiniDbg

Налагоджувач для Windows x64, написаний з нуля на C

48895C242055488B

Відладчик зупиняє чужу програму й показує її процесор

MiniDbg запускає native Windows x64 програму під Windows Debug API. Увесь код на C, окрім WinAPI жодних залежностей.

Шість команд

break addr
Точка зупинки, що спрацьовує щоразу
Breakpoint 1 set at 0x…1300.
continue
Виконувати до наступної зупинки або кінця
Hit breakpoint 1 at 0x…1300.
step
Рівно одна інструкція процесора, не рядок C
Step at 0x…1304 (one instruction)
regs
Регістри x64 і EFLAGS, зміни позначені *
RIP=0x…1304 *
mem addr n
До 256 байт пам’яті: hex + ASCII
48 89 5C 24 20 55 48 8B |H.\$ UH.|
quit
Завершити ціль і закрити сеанс
Process exited with code 1.
Адреси без копіювання:break entrybreak base+1740mem rsp 32mem rip 16

  3. 3

  4. 4

  5. 5

    Програма біжить даліContinueDebugEvent

1. зупинкаПотік A виконав 0xCC. Windows надіслала EXCEPTION_BREAKPOINT, програма стоїть.

2. байт знятоОригінальний байт повернуто, B призупинено, щоб він не проскочив повз зняту точку.

3. зарядженоПісля кроку знову 0xCC, потоки відновлено. Тест: одна точка у двох потоках, 20 запусків.
